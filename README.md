# Computer Performance Modeling

Coursework and projects developed for the **Computer Performance Modeling** course in the Software Engineering program at PUCRS.

Topics include discrete-event simulation, pseudorandom number generation, queueing systems, performance evaluation, and analytical modeling.

## Projects

- [`queue-simulator-m4`](./queue-simulator-m4) — discrete-event simulator for finite-capacity queues.

New activities will be added as the course progresses.
